# Contributing

Contributions are welcome! Please open an issue describing model format, target device, runtime, expected evidence and security impact. Add deterministic fixtures, negative tests, and documentation. For hardware-specific PRs include real device/OS/runtime versions, model or synthetic fixture provenance, sample sizes and limitations. Never commit model weights or private data without permissions. Run `npm test`, `npm run demo`, and include output summaries; obtain approval for third-party dependencies. Follow CODE_OF_CONDUCT.md and SECURITY.md.
