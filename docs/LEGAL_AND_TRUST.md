## What ships
- **No third-party code**: zero runtime npm dependencies; Node.js built-ins only.
- **No model weights or datasets**: fixtures are synthetic protobuf stubs written for tests. Nothing is downloaded at install or run time.
- **No external resources in reports**: inline CSS, no fonts, scripts, trackers or CDN calls.

## Privacy
No telemetry. No network access in the CLI (the optional `serve` binds `127.0.0.1`). Host id in reports is a short SHA-256 of the hostname. Serial numbers, user names and paths outside the supplied inputs are not collected. Report files are written with mode `0600` on POSIX.

## Claims discipline (consumer-protection posture)
Marketing and reports must not state: that a model "runs on" a device, that INT8 is faster or lower power, energy or carbon figures, or "secure" / "vulnerability-free". The tool enforces this in output: such values are `NOT_RUN` / `NOT_MEASURED`.

## Export, safety and regulated use
The tool is analysis-only. It does not flash firmware, change clocks, install drivers or deploy models. It must not be the sole evidence for safety-critical (medical, automotive, aviation) release decisions.

## Third-party model licenses
Users are responsible for the license of any model they analyze. EdgeSutra records a SHA-256 and operators, not license entitlement.

## Independent-audit stance
Every number in public docs is regenerated by `npm run proof` and tied to a log in `docs/proof/`. Anything not run is labelled so. See [proof](proof/README.md).
