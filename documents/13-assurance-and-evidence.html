Not verified (stated plainly)

  • Any behavior on a real edge device.
  • Real ONNX Runtime / LiteRT / ExecuTorch execution.
  • Native skill loading in each IDE.
  • Windows symlink-refusal behavior (tests skip locally; exercised on Linux/macOS CI).
  • Third-party penetration test or formal code audit.
  • Trademark clearance.

Reproduce it yourself

git clone https://github.com/shahvatsalofficial/edgesutra-ai && cd edgesutra-ai
npm test
npm run proof     # regenerates docs/proof/*
npm run audit     # regenerates examples/reports/audit/*

Compare your SHA256SUMS.txt against the committed one (timestamps and timings differ; structure and verdicts must match).

Auditor's conclusion

The software does what its documentation says within a deliberately narrow scope, refuses to overclaim, and its tests and fuzzing found and closed a real defect. It must not be used as proof that a model works on a device. That requires P3.
