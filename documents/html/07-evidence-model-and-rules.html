What it says and never says#

It will say

  • "Declared operators are missing from the runtime."
  • "Declared memory exceeds the device."
  • "This toy model ran in a measured time on this host, not on your device."
  • "Device execution: NOT_RUN."

It will never say

  • "Runs on your Raspberry Pi."
  • "INT8 is faster / uses less power."
  • "Energy: 0 Wh" (it prints NOT_MEASURED).
  • "Ready to ship." (best verdict is REVIEW_REQUIRED)

Verdicts#

BLOCKED

A static check failed. Exit code 1. Stop and fix the model, runtime or device choice.

REVIEW_REQUIRED

No static check failed, but nothing ran on the device. Exit code 0. A human collects device evidence.

GO_CANDIDATE

Reserved. Needs verified on-device evidence and human sign-off. This release cannot emit it.

Language rules#

  1. Never write "runs on", "supported on" or "optimized for" a device without MEASURED_ON_DEVICE.
  2. INT8 / INT4 are precision labels, not speed or power claims.
  3. Missing values are NOT_MEASURED, never zero.
  4. Same file name with different bytes is a different artifact (SHA-256 identity).
  5. Latency, throughput, quality, memory, energy and cost are separate metrics.
