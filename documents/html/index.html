How it works

From your files to a sealed report

Point it at model, device and runtime descriptions, or a real ONNX file. It checks what can be checked offline, times what can be timed on this machine, and writes down everything it could not do.

Audit

One command, three report formats.

edgesutra audit --out ./edge-audit
# or your own inputs
  --onnx model.onnx

Gate

Exit code 1 stops the pipeline on a failed check.

edgesutra check \
  --model m.json --device d.json \
  --runtime r.json

Verify

Recompute the integrity seal on any report.

edgesutra verify \
  --input audit-report.json
The idea

Five levels of evidence. Only some are real today.

Most tools blur these together. EdgeSutra labels every artifact with its tier and refuses to promote one to another.

5

MEASURED_ON_DEVICE

Ran on a named physical or virtual target, with logs and samples.

Not yet
4

IMPORTED_MEASUREMENT

Numbers supplied by someone else, with provenance.

Planned
3

MEASURED_HOST_ONLY

Timed on the machine running the tool. Real, but not the target.

Produced
2

STATIC_MATCH

Declared model, runtime and device manifests agree.

Produced
1

NOT_RUN / UNKNOWN

Honestly absent. Never rounded up to a pass or a zero.

Always shown
Honest by construction

What it says, and what it never will

The report language is enforced in code and tested, not just documented.

It will say

  • "Declared operators are missing from the runtime."
  • "Declared memory exceeds the device."
  • "This toy model ran in a measured time on this host, not on your device."
  • "Device execution: NOT_RUN."

It will never say

  • "Runs on your Raspberry Pi."
  • "INT8 is faster / uses less power."
  • "Energy: 0 Wh" (it prints NOT_MEASURED).
  • "Ready to ship." (best verdict is REVIEW_REQUIRED)

Three verdicts, one of them locked

BLOCKED

A static check failed. Exit code 1. Stop and fix the model, runtime or device choice.

REVIEW_REQUIRED

No static check failed, but nothing ran on the device. Exit code 0. A human collects device evidence.

GO_CANDIDATE

Reserved. Needs verified on-device evidence and human sign-off. This release cannot emit it.

What it does not do

  • It does not run models on edge devices. Device execution is always NOT_RUN.
  • ONNX inspection reads metadata only: no graph validation, no inference.
  • No ONNX Runtime, LiteRT, ExecuTorch or llama.cpp execution yet.
  • SHA-256 detects change. It is not a signature and does not prove origin.
