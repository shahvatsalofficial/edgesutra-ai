## Honest notes
- **Skipped tests** are the four symlink-refusal tests. Windows without Developer Mode forbids creating symlinks, so the test cannot construct its attack input; it skips explicitly. These run on Linux and macOS CI.
- One machine, one run. See GitHub Actions for the OS/Node matrix.
- Defect found by this process: the ONNX reader threw a `TypeError` on invalid UTF-8 (205 of 2000 fuzz inputs). Fixed in 0.2.0 and covered by a regression test.
- Tests are hermetic: no downloads, no network.
